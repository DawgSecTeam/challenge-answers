EASY: User Account Control is enabled (EnableLUA = 1) 2 pts

Goal: the checked condition must hold  ·  Scored on: a live on-box probe

1. See the state. With UAC's EnableLUA switched off, every administrator token is full admin all the time -- no consent prompt, and code running as an admin needs no elevation step to own the box:

reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" /v EnableLUA
    EnableLUA    REG_DWORD    0x0

2. Turn it back on:

reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" /v EnableLUA /t REG_DWORD /d 1 /f

GUI route: regedit to the same key. The consent-prompt slider in Control Panel is cosmetic here -- the scored bit is EnableLUA itself.

3. Confirm. The reg query reads 0x1. Fresh tokens appear at the next sign-in, but the check reads the value, so the point lands immediately.

EASY: UAC prompts before elevating again (consent behavior restored) 2 pts

Goal: the checked condition must hold  ·  Scored on: a live on-box probe

1. Read the toggle. EnableLUA is only half of UAC -- check what elevation DOES now:

reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" /v ConsentPromptBehaviorAdmin
    ConsentPromptBehaviorAdmin    REG_DWORD    0x0

0 means every elevation happens silently -- the consent dialog, the one checkpoint where a user notices something is wrong, is gone.

2. Restore the prompt (delete the value or set it back to the default 5):

reg delete "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" /v ConsentPromptBehaviorAdmin /f

3. Confirm. The reg query errors "unable to find ... value" (or reads a non-zero value).

EASY: LLMNR name-resolution broadcast is disabled 2 pts

Goal: the checked condition must hold  ·  Scored on: a live on-box probe

1. Notice the default. Nothing was planted -- Link-Local Multicast Name Resolution ships enabled, and it is the protocol that lets ANY machine on the segment answer a mistyped hostname and harvest the authentication hashes that follow (a responder-in-a-corner attack needs nothing but this default):

Get-ItemProperty 'HKLM:\SOFTWARE\Policies\Microsoft\Windows NT\DNSClient' -Name EnableMulticast

(the value being absent means the default -- on -- is in force).

2. Switch it off via policy:

gpedit.msc > Computer Configuration > Administrative Templates >
  Network > DNS Client > "Turn off multicast name resolution" > Enabled

(which writes EnableMulticast=0 here; a direct reg add scores the same.)

3. Confirm. The Get-ItemProperty above reads 0.
